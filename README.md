# Awesome AI Security Assistant

**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Agentic SOC, Alert Triage, Threat Investigation & Automated Response*
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **AI Security Assistants**. These tools help SOC analysts and security teams investigate alerts, prioritize threats, and automate response actions using AI agents that reason across telemetry.

**Examples** include Microsoft Copilot for Security, Google Security AI Workbench, SentinelOne Purple AI, CrowdStrike Charlotte AI, Palo Alto Cortex XSIAM, Wiz Defend AI, Recorded Future AI, Splunk AI Assistant, Tenable ExposureAI, and Cisco AI Assistant for Security (the category leaders).

**Open-source emphasis**: The open-source ecosystem for AI security assistants is **emerging and production-capable at the orchestration layer**. **Allama** provides a self-hosted AI security automation platform with visual workflows, 80+ integrations, and support for local LLMs via Ollama . **AiSOC** delivers a full open-source AI SOC with alert fusion, LLM-agent triage, MITRE ATT&CK investigation, and a replayable decision ledger . **Amygdala** connects to Splunk via MCP and uses Foundation-Sec-8B for autonomous alert triage . **Sentora** offers a self-hosted AI-powered SIEM, EDR, and SOAR platform . **Security Shallots** brings a lightweight SIEM that runs on anything from a Raspberry Pi to a full server . This section documents these production-grade solutions.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Microsoft Copilot for Security](https://securitycopilot.microsoft.com/)**  
  **Microsoft's AI security assistant integrated across Defender, Intune, Purview, and Entra.** **Included with Microsoft 365 E5/E7** at no additional cost—every 1,000 licenses grants 400 Security Compute Units (SCUs) monthly . **SCU consumption**: Usage is metered; overages cost **$6 per additional SCU per hour** on pay-as-you-go . **Capabilities**: Phishing triage, access control optimization, data protection, incident summarization, and guided response. **Perception** (announced 2026) adds autonomous red/blue/green agent teams for code remediation and vulnerability patching beneath the Copilot interface . **Cost warning**: Aragon Research estimated that 50 Security Copilot users consuming 32 SCUs/hour would cost **$93,440/month**—enterprises should use the SCU calculator before committing . **Best for**: Organizations with Microsoft E5/E7 wanting native AI security assistance.

- **[SentinelOne Purple AI](https://www.sentinelone.com/platform/purple-ai/)**  
  **Agentic AI security analyst built natively into the Singularity Platform.** **Agentic Investigation** (GA June 2026) runs **zero-click, autonomously initiated investigations**—detects, investigates, verifies, and responds to threats without human dependencies . **Scale**: Running in customer environments since June 2026, handling **8,500+ critical autonomous investigations daily**; more than one-third of eligible customers have it enabled; investigates **nearly 3× as many alerts as analysts handle manually** . **Multi-model approach**: Combines Anthropic Claude, OpenAI GPT, and SentinelOne's proprietary "Ultraviolet" models . **Governance**: Every verdict carries a complete, auditable evidence chain; customers set autonomy levels via adjustable human-in-the-loop controls; activation is admin-controlled and reversible . **Pricing**: **Singularity Credits** as unified currency; complimentary allotment for trials . **Best for**: Existing SentinelOne customers wanting autonomous investigation without adding headcount.

- **[CrowdStrike Charlotte AI](https://www.crowdstrike.com/platform/charlotte-ai/)**  
  **Agentic AI analyst built natively on the Falcon platform.** **Performance**: **>98% decision accuracy** on agentic detection triage; **70% reduced manual effort** during investigations; **90% reduced incident response time**; **3× faster MTTR** . **AgentWorks**: No-code agent builder for custom security agents using the model of your choice. **Charlotte Agentic SOAR**: Unites agentic reasoning with deterministic workflows in a governed workspace. **Governance**: ISO 42001-certified for AI governance; every answer traces back to source data; every action is bounded, user-authorized, and logged . **Best for**: CrowdStrike customers wanting an agentic SOC workforce with governed autonomy.

- **[Palo Alto Cortex XSIAM](https://www.paloaltonetworks.com/cortex/cortex-xsiam)**  
  **AI-driven security operations platform with Agentic Assistant.** **Cortex Agentic Assistant** (evolved from Cortex Copilot) uses autonomous agents based on **1.2 billion real-world playbook executions** to dynamically plan, reason, and act . **Availability**: Included in XSIAM; **no charge** for agentic agents at this time (must be enabled in server settings) . **Native MCP support**: Cortex MCP Server (Beta) connects trusted LLM applications to XSIAM for real-time data access via natural language . **Best for**: Organizations in the Palo Alto ecosystem wanting agentic security operations.

- **[Wiz Defend AI (Blue Agent)](https://www.wiz.io/blog/wiz-blue-agent-generally-available)**  
  **AI-driven cloud incident response agent with full cloud context.** **Blue Agent** (GA March 2026) automatically triages every new threat in Wiz, collecting context from across the cloud environment and generating a transparent verdict in moments . **Specialized sub-agents**: **Forensics** analyzes automatically collected forensics packages (scripts, binaries, artifacts); **Code Analysis** correlates runtime activity back to source code, PRs, and code owners . **Transparency**: Shows every step of its reasoning—no black boxes . **Wiz Workflows**: Turn verdicts into action—escalate incidents, notify teams, or trigger containment playbooks . **Best for**: Wiz Defend customers wanting cloud-native AI investigation.

- **[Recorded Future AI](https://www.recordedfuture.com/platform/ai)**  
  **AI-powered threat intelligence and alert filtering.** **AI Alert Filtering** (GA August 2026) automatically filters alerts by relevance before an analyst opens them—**customers saw ~63% average reduction in alert volume** . **Intelligence Graph**: Every AI decision is grounded in Recorded Future's threat intelligence, not just text . **Capabilities**: AI Sessions for on-demand intelligence Q&A; AI Insights for automatic entity surfacing; AI Report Creation for template-based or custom reports; **MCP server** extends intelligence into any tool or agent . **No data loss**: Changes what gets surfaced, not what gets stored . **Best for**: Teams drowning in threat intelligence alerts wanting AI-powered prioritization.

- **[Splunk AI Assistant in Security](https://help.splunk.com/en/splunk-enterprise-security/8.4/administer/ai-assistant-in-security-and-agentic-capabilities)**  
  **AI assistant embedded in Splunk Enterprise Security.** **Summary Skill**: Generates concise alert summaries with **MITRE ATT&CK mapping** and recommended next steps . **SPL Generation**: Converts natural language to SPL queries for investigation . **Report Generation**: Creates investigation reports that can be saved as PDF, notes, or attachments . **Model**: Powered by Cisco's **Foundation-Sec-8B-1.1-Instruct** custom-tuned security model, replacing Llama-3.1-70B for better latency and consistency . **Availability**: All Enterprise Security customers on Splunk-hosted AWS cloud . **Best for**: Splunk ES customers wanting embedded AI assistance.

- **[Tenable ExposureAI](https://www.tenable.com/products/exposure-ai)**  
  **AI-powered exposure management with third-party data connectors.** Named **"Company to Beat" in Gartner's 2025 AI Vendor Race for AI-Powered Exposure Management** . **Tenable One AI Exposure**: Comprehensive, risk-oriented visibility into where AI exists, how it's connected, and where exposure begins . **Capabilities**: Discovers internal and external AI usage, maps AI workflows and access paths, identifies excessive permissions and identity vulnerabilities . **Third-party connectors** unify data into single dashboards . **Best for**: Organizations wanting to secure AI adoption itself (AI-SPM) alongside traditional exposure management.

- **[Cisco AI Assistant for Security](https://www.cisco.com/c/en/us/support/docs/security/secure-firewall-management-center/226077-configure-and-troubleshoot-ai-assistant.pdf)**  
  **AI assistant for Cisco Secure Firewall Management Center.** **Capabilities**: Answers configuration questions, helps create policy rules, diagnoses and resolves firewall-related issues . **Rule Creation**: Natural language to structured policy rules (e.g., "Allow YouTube for Test network")—rules created in **disabled state** for administrator review . **Security**: Tenant-isolated (cannot access other tenants' policies); no PII collection . **Notification Center**: Real-time and scheduled alerts for policy analysis and rule activation . **Requirement**: Administrator role; outbound internet access; Security Cloud integration . **Best for**: Cisco firewall administrators wanting AI-assisted policy management.

## Open-Source GitHub Projects

### Full AI SOC Platforms

- **[Allama](https://github.com/digitranslab/allama)**
  **Open-source AI security automation platform—self-hosted SOAR alternative.** **Key features**: **Visual workflow builder** — drag-and-drop security playbooks with conditional logic, parallel execution, and loops, no code required; **AI-powered agents** — autonomous agents that understand threats, make decisions, and execute responses; **80+ integrations** — SIEM (Splunk, Elastic, Wazuh, Datadog), EDR (CrowdStrike, SentinelOne), Identity (Okta, Entra ID), Ticketing (Jira, PagerDuty), Communication (Slack, Teams), Threat Intel (VirusTotal, URLScan), Cloud (AWS, GCP, Kubernetes); **Case management** with full audit trails; **Secure script execution** in WebAssembly sandboxes . **Architecture**: FastAPI API gateway, Temporal workflow engine (durable execution with retries), PydanticAI + LiteLLM for multi-model support, PostgreSQL, S3-compatible object storage . **Security**: SSO (Google, SAML), RBAC, AES-256 secrets encryption, complete audit history . **Deployment**: Docker with `make init` and `make dev`; requirements: 4GB RAM, 10GB disk . **Claimed performance**: 90% faster triage . **Best for**: SOC teams and MSSPs wanting a self-hosted AI-powered SOAR with visual workflows.

- **[AiSOC](https://github.com/beenuar/AiSOC)**
  **Open-source AI Security Operations Center with alert fusion and LLM-agent triage.** **MIT licensed**, self-hostable, runs with no API keys (bundled model) . **Key features**: **Alert fusion** — correlates alerts into incidents; **LLM-agent triage** with typed tools (lake queries, graph traversals, enrichment lookups)—model chooses tools but never writes SQL; **Investigation Ledger** — every prompt, tool call, citation, verdict, and token cost is logged; **Grounding checks** — verdicts citing indicators not in evidence are demoted to human review; **Human-in-the-loop** — nothing executes without an approver who holds the required permission tier and is not the requester . **Maturity**: Detection engine with **2,603 executable rules** (of 6,991); alert correlation into incidents; REST API + web console; AI triage + Investigation Ledger (Beta); Event lake + hunting (ClickHouse); Entity graph (Neo4j); Governed response actions (human-approved only); UEBA; SCIM 2.0; white-label . **What it is not**: Not a drop-in SIEM replacement; not autonomous by default; demo incidents are not real incidents . **Best for**: Teams wanting a governed, auditable AI SOC foundation with human approval gates.

- **[Sentora](https://github.com/d3vhex/Sentora)**
  **Open-source, self-hosted AI-powered SIEM, EDR, and SOAR platform.** **Key features**: **Agent-based** (Windows/Linux) with log ingestion via RabbitMQ; **AI worker fleet** with 3 modes; **Threat intel** from AlienVault OTX, VirusTotal, and abuse.ch feeds (Feodo Tracker, ThreatFox, URLhaus) with staleness pruning (30-day default); **Air-gap mode** (`OSV_MODE=mirror`, `THREAT_INTEL_MODE=off`)—nothing leaves the network; **Fleet exposure reporting** counting unpatched packages and file-integrity events per agent; **Agent config validation** with regex compilation checks before pushing to sensors . **Architecture**: Sanic API (:8000), React UI, WebSocket screen proxy, MySQL per-agent databases, RabbitMQ, AI worker fleet . **Security**: Fernet encryption at rest, `chmod 600` key files, no in-place rotation yet . **Best for**: Organizations wanting a self-hosted AI-augmented SIEM with EDR and SOAR capabilities.

### Agentic SOC Analysts

- **[Amygdala](https://github.com/supernerve-dev/amygdala)**
  **Open-source agentic SOC analyst that connects to Splunk via MCP.** **Key features**: Continuously pulls alerts via SPL queries; feeds them into **Foundation-Sec-1.1-8B** (Splunk's security-specialized LLM) for threat classification and severity triage; **spawns investigation sub-agents** that correlate related events, trace lateral movement, enrich context, and score risk; outputs **structured incident report (JSON) plus human-readable summary** pushed to Slack or webhook in seconds . **Zero human-in-the-loop unless escalation threshold is hit** . **Architecture**: Python 3.12+, Splunk MCP server, Foundation-Sec model endpoint (local via Ollama or remote), Docker containerized . **Demo mode**: `python -m amygdala.main --demo` uses sample alerts without Splunk . **Best for**: Splunk customers wanting autonomous alert triage and investigation reports.

- **[Agentic AI Security Operations Platform](https://github.com/golden-horizon/agentic-ai-security-operations-platform)**
  **AI-powered SOC Analyst Agent built with Python, Ollama, Qwen, MITRE ATT&CK, MCP, and modular agent architecture.** **Key features**: **Eight coordinated agents** — Log Collection, Detection, MITRE ATT&CK, Threat Intelligence, Correlation, Severity Escalation, Case Management, Investigation; **Threat intelligence enrichment** (IP reputation, geographic attribution, threat scoring); **MITRE ATT&CK mapping** (SQL Injection → T1190, Brute Force → T1110, XSS → T1059); **Case management** with analyst notes and investigation updates; **Security monitoring dashboard** with incident tracking, AI-escalated cases, threat intel panel, MITRE context, executive dashboard, threat hunting workspace . **Architecture**: Python, FastAPI, React, Vite, Socket.IO, REST APIs, Multi-Agent Workflow Engine, GitHub Actions CI/CD . **Local LLM ready**: Designed for Ollama, Qwen, on-premise security LLM deployments . **Best for**: Teams wanting a modular multi-agent SOC architecture with local LLM support.

### Lightweight & Specialized Platforms

- **[Security Shallots](https://pypi.org/project/security-shallots/)**
  **Lightweight, self-hosted SIEM that runs on anything—from a Raspberry Pi to a full server.** **No Splunk. No Elastic. No Docker required.** Just Python and SQLite . **Key features**: **Ingests** from Suricata IDS, Syslog, pfSense, Wazuh, CrowdSec, Pi-hole, Argus endpoint agents, and web app logs; **Normalizes** alerts into common format; **Deduplicates** repeated noise; **Auto-classifies severity** and suppresses known false positives; **Correlates patterns** (port scans, brute force, lateral movement); **Groups related alerts into incidents** with response runbooks; **Optional AI triage** via OpenAI/Anthropic API—no local GPU needed; **Web dashboard** with real-time WebSocket feed . **Hardware auto-detection**: Adjusts based on available RAM/CPU—Raspberry Pi (2GB/1core) runs Suricata + syslog + basic correlations; full server (16GB+/8+cores) runs full threat engine with baselines, graph, ML, kill chain . **Resource usage**: ~200-400 MB RAM on 4GB machine with threat engine disabled; 30 days of home network alerts uses ~200-500 MB SQLite . **Quick start**: `curl ... | sudo bash` one-line installer; `pip install git+https://github.com/benolenick/security-shallots.git` manual . **Best for**: Home labs, small businesses, and resource-constrained environments wanting AI-augmented SIEM without enterprise complexity.

- **[CSage](https://pypi.org/project/csage/)**
  **Professional AI-powered cybersecurity testing assistant for developers and security researchers.** **Navigator Model**: Intent-driven pipeline where AI acts as expert consultant—analyzing targets, formulating step-by-step testing plans, providing precise explained commands—**while you maintain absolute control over execution** . **Key features**: **Smart tool discovery** — automatically detects, installs, and configures nmap, sqlmap, gobuster, etc.; **Hybrid AI engine** — switch between local models (Ollama, LM Studio) and cloud (Groq, OpenAI, Gemini); **Tamper-evident logging** — every command and finding recorded in HMAC hash-chained log for forensic integrity; **Security checkpoints** — high-risk operations require explicit user confirmation and re-authentication . **CLI**: `csage scan --url <url>`, `csage model`, `csage logs --verify`, `csage tools install` . **Interactive session**: `[next]`, `[run]`, `[paste]`, `[ask]`, `[report]`, `[model]`, `[quit]` . **Installation**: `pip3 install .`; auto-installs dependencies on first run . **Best for**: Security researchers wanting AI-guided penetration testing with human-controlled execution.

- **[Anymous](https://www.npmjs.com/package/anymous)**
  **AI-powered reverse engineering and pentest platform with 44 AI agents for reverse engineering, pentest, SOC, and engineering.** **64 free models, no API key required.** Unrestricted mode for professionals . **Agents include**: SOC (lead), Forensics (lead), Red Team (lead), Blue Team (lead), Reverse Engineering (8 agents: reverser-static, reverser-dynamic, reverser-binary, reverser-source, reverser-automator, memory-dump, exe-extractor, debug-tools), Pentest (10 agents: pentest-lead, recon, scanner, enumerator, exploiter, identity, webapp, postexploit, critic, reporter), Cyber-analytic (SOC), Engineering (20 agents) . **Quick tasks**: `anymous run --agent soc "analisa este alerta"`, `anymous run --agent redteam "alvo lab 10.10.10.0/24"`, `anymous run --agent blueteam "hardening deste servidor"`, `anymous run --agent forensics "analisa este dump"` . **Providers**: 64 free opencode models out of the box, plus any opencode-compatible provider (OpenAI, Anthropic, Google, OpenRouter) . **MIT License** . **Best for**: Penetration testers and reverse engineers wanting AI agent assistance across multiple security domains.

### Research & Academic Frameworks

- **[AI-Driven Incident Response with Wazuh MCP (IEEE 2026)](https://ieeexplore.ieee.org/document/11642294)**
  **Academic evaluation of AI-assisted incident response with Wazuh SIEM and MCP.** **Phase 0 (manual baseline)**: 83.33% detection rate, 10.04 min analysis time, 846 min dwell time, 804 min MTTR . **Phase 1 (AI-assisted, human-in-the-loop)**: **91.67% detection rate** (+8.34pp), **1.23 min analysis time** (-88%), **222 min MTTR** (-72%), **222 min dwell time** (-74%) . **Phase 2 (fully automated active-response)**: **0.15 min analysis time** (-98.5%), **15.2 min MTTR** (-98.1%), **13.9 min dwell time** (-98.4%), **87.50% precision, 8.33% false-positive rate** . **Conclusion**: MCP-based AI support significantly improves analyst efficiency, response speed, and risk exposure; fully automated response further optimizes MTTR and dwell time **provided adequate SIEM rule coverage** . **Best for**: Researchers and architects wanting quantified benchmarks for AI-assisted SOC workflows.

- **[OpenSIEM](https://xplorestaging.ieee.org/document/11113996)**
  **Unified open-source security management framework integrating Wazuh, TheHive, Shuffle, Elasticsearch, Logstash, Kibana, MISP, VirusTotal, OpenCTI, and Apache Cassandra.** **Ingests and processes 10,000+ security logs per second** with only **5% of alerts requiring manual investigation** . **Results**: **40% reduction in false positives**, **70% improvement in incident response time** . **Contributions to UN SDGs**: SDG 9 (Industry/Innovation/Infrastructure), SDG 16 (Peace/Justice/Strong Institutions), SDG 17 (Partnerships) . **Best for**: Organizations wanting a proven open-source SIEM stack with automation and real-time response.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- AI security assistants access sensitive security telemetry and may take automated response actions; ensure proper access controls, human approval gates, and compliance with organizational security policies before deployment.
- **Open-source reality**: The open-source ecosystem for AI security assistants is **emerging and production-capable at the orchestration layer**. **Allama** provides a self-hosted AI security automation platform with visual workflows and 80+ integrations . **AiSOC** delivers governed AI triage with a replayable Investigation Ledger and human approval requirements . **Sentora** offers a self-hosted SIEM/EDR/SOAR with air-gap mode . **Amygdala** connects to Splunk via MCP for autonomous alert triage . **Security Shallots** runs on anything from a Raspberry Pi to a full server . However, **commercial platforms** (Microsoft Copilot for Security, SentinelOne Purple AI, CrowdStrike Charlotte AI, Palo Alto Cortex XSIAM) provide **managed infrastructure, enterprise support, and deep integration with proprietary telemetry** that open-source alternatives require additional configuration to match. The open-source path is **genuinely viable** for organizations with strong security engineering capacity seeking full data sovereignty and human-controlled automation.
